# 🐾 PetCare — Sistem Penitipan Hewan

**PetCare** adalah aplikasi web untuk mengelola layanan penitipan hewan peliharaan. Project ini dikembangkan menggunakan PHP dan MySQL dengan sistem login multi-role untuk Admin dan User.

## ✨ Fitur Utama

- **Login Multi-Role:** Akses berbeda untuk Admin dan User.
- **Manajemen Pengguna:** Mengelola akun pengguna.
- **Manajemen Hewan:** Mengelola data berbagai hewan, seperti anjing, kucing, burung, reptil, ikan, kelinci, dan hamster.
- **Manajemen Kandang:** Mengelola kandang dan wadah sesuai jenis hewan.
- **Manajemen Layanan:** Mengelola layanan perawatan dan harga.
- **Booking Penitipan:** Mencatat transaksi penitipan hewan.
- **Pembayaran:** Mengelola nominal, metode, dan status pembayaran.
- **Rekap Bulanan:** Melihat ringkasan pembayaran dan pendapatan berdasarkan bulan.

## 🛠️ Teknologi

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap/XAMPP (sesuai teknologi yang digunakan dalam project)

## 🚀 Cara Menjalankan

1. Install dan jalankan Apache serta MySQL melalui XAMPP.
2. Letakkan folder project di direktori `htdocs`.
3. Buat database `penitipan_peliharaan` melalui phpMyAdmin.
4. Import struktur database yang tersedia.
5. Sesuaikan konfigurasi database pada `config/koneksi.php`.
6. Buka project melalui browser menggunakan `http://localhost/PetCare/`.

## 🎯 Tujuan Project

Project ini dibuat sebagai sarana pembelajaran pengembangan aplikasi web, pengelolaan database relasional, CRUD, autentikasi pengguna, serta pengolahan transaksi penitipan dan pembayaran.
